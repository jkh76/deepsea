# 🌊 해저탐험 (Deep Sea Adventure) 웹 게임

보드게임 **해저탐험(Deep Sea Adventure, Oink Games)** 을 브라우저에서 즐길 수 있게 만든 개인용 웹 게임입니다.
`index.html` 파일 하나로 동작하며, 애니메이션은 [GSAP](https://gsap.com/)을 사용합니다.

## 플레이 방법

- `index.html`을 브라우저로 열거나 GitHub Pages(`main` 브랜치)로 배포해서 플레이합니다.
- GSAP을 CDN에서 불러오므로 인터넷 연결이 필요합니다.
- 2~6인, 플레이어마다 **사람 / AI**를 선택할 수 있습니다(한 화면에서 돌아가며 플레이).

## 규칙 요약

- 모든 잠수부는 잠수함 하나와 **산소 25**를 함께 씁니다. 총 **3라운드**, 확보한 보물 점수 합계가 높은 사람이 승리합니다.
- 보물 칩 32개: 레벨 1(△ 0~3점), 레벨 2(□ 4~7점), 레벨 3(⬠ 8~11점), 레벨 4(⬡ 12~15점). 깊을수록 비쌉니다.
- 내 차례 진행
  1. **산소 감소**: 들고 있는 보물 수만큼 공용 산소가 줄어듭니다.
  2. **방향 결정**: 내려갈지, 잠수함으로 올라갈지 정합니다. 한 번 올라가면 그 라운드에는 다시 내려갈 수 없습니다.
  3. **이동**: 주사위 2개(각 1~3) 합 − 들고 있는 보물 수만큼 이동합니다. 다른 잠수부가 있는 칸은 세지 않고 건너뜁니다.
  4. **탐색**: 보물 캐기 / 빈 상자 칸에 보물 내려놓기 / 그냥 지나가기 중 하나를 고릅니다.
- **산소가 0이 되면** 그 턴은 끝까지 진행한 뒤 라운드가 끝납니다(나무위키 기준 해석).
- 잠수함에 돌아오지 못한 잠수부는 보물을 모두 잃습니다. 잃은 보물은 3개씩 묶여 바다 맨 끝으로 가라앉고, 묶음은 보물 1개로 취급합니다.
- 다음 라운드는 빈 칸을 정리하고, 가장 깊이 있던 잠수부부터 시작합니다.

## 주요 기능과 연출

- 시작 시 **룰렛**으로 1번 차례를 뽑고, 나머지 순서는 랜덤으로 정합니다.
- 물결치는 **유선형 보드**와 상어·바다거북이 헤엄치는 배경
- 방향 선택 카드, 말에 붙은 **↓ / ↑ 방향 화살표**와 보유 보물 개수
- 보물을 캘 때 곡괭이·흙먼지·반짝임 연출과 줌인, 캔 자리는 **열린 빈 보물상자**로 표시
- 산소가 5 이하가 되면 라운드당 한 번 **"산소부족! 산소부족!" 경고 + 사이렌**
- 효과음은 Web Audio로 직접 합성(외부 음원 파일 없음)
- **드래그**로 화면 이동, **마우스 휠 / 두 손가락**으로 확대·축소, 🔍 전체보기 버튼
